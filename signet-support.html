Help for Signet on Android  ·  Last updated: 12 August 2026

Signet adds text or transparent-logo watermarks to batches of photos on your device. This page covers the initial unlimited Android release.

Contact support

Email kovalchuk.egor1357@gmail.com. Please include your Signet version, phone model, Android version, the output format and the exact message shown by the App.

Do not email private source photos, watermark logos or metadata unless we specifically agree that one sample is necessary. Remove sensitive information first.

Start a watermark job

  1. Open Signet and choose Select photos or import from Files.
  2. Select one or more JPEG or PNG photos using Android’s system picker.
  3. Add a text watermark or transparent PNG logo.
  4. Review placement across portrait, landscape and square photos.
  5. Adjust an individual photo if it needs a different position or visibility.
  6. Choose JPEG or PNG output and start export.
  7. Use the completion screen to find the successfully saved copies.

Original photos

Signet opens selected source photos as read-only content. It never overwrites them. Every successful export is a new file. If a job fails or is cancelled, Signet does not report a partial output as complete.

Supported limits in the first release

  • Android 7.0 or newer.
  • JPEG and PNG photo export.
  • Text and transparent PNG logo watermarks.
  • Maximum 13,000,000 oriented pixels per selected image. For example, common 12–12.98 MP camera photos are within this measured limit.
  • Actual batch capacity depends on image dimensions, format, available memory, free storage and the phone.

Images over the supported pixel limit are rejected before export to reduce the risk of the operating system terminating the job.

Common problems

A photo cannot be read

  • Open the photo in your gallery to confirm it is still available.
  • Try selecting it again through the system picker.
  • If it is cloud-only, download the original to the device first.
  • Convert an unusual or damaged file to a standard JPEG or PNG.

An export failed

  • Check that the device has free storage.
  • Keep Signet open while retrying a very large batch.
  • Retry only the failed items from the result screen; successful siblings should not be duplicated.
  • Try JPEG output if a very large PNG job exceeds the device’s available memory.

I cannot find the output

  • Use the completion screen’s destination action.
  • Check your Photos/Gallery app and its recent items.
  • If you selected a Files destination, reopen that folder through Android’s Files app.

The App was closed during export

Reopen Signet. The active draft should return, while an incomplete output should not appear as successful. Review the recovered job and retry the items that did not finish.

Does Signet need internet access?

No for the core workflow. Photo selection, watermark editing, preview and export work on-device. The initial release has no ads, subscriptions or enabled remote diagnostics.

Accessibility

Signet supports Android text scaling and TalkBack on the main workflow. If an action is clipped, unlabeled or difficult to reach, report the screen, font-size setting and TalkBack state.

What to include in a useful report

  • Signet version and build number from Settings.
  • Phone manufacturer and model.
  • Android version.
  • JPEG or PNG output.
  • Number of photos and approximate megapixels.
  • Whether the watermark was text or a logo.
  • The exact error message and the step where it appeared.
